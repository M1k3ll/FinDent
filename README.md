# Findent

برنامه‌ی تحت وب برای پیدا کردن **پرونده‌ی کاغذی بیماران** یک مطب دندان‌پزشکی.
منشی با کدملی، موبایل، شماره پرونده یا نام خانوادگی جستجو می‌کند و برنامه شماره و محل نگهداری پوشه را نشان می‌دهد.

## نصب (فقط یک بار، روی ویندوز)

1. **Python 3.11 یا جدیدتر** را از python.org نصب کنید. در نصب، گزینه‌ی *Add python.exe to PATH* را تیک بزنید.
2. روی **`setup.bat`** دو بار کلیک کنید (به اینترنت نیاز دارد). این فایل همه‌چیز را آماده می‌کند و در پایان نام کاربری و رمز **مدیر** را می‌پرسد.
3. (اختیاری ولی پیشنهادی) فونت وزیرمتن را طبق `static/fonts/README.txt` اضافه کنید.

## استفاده‌ی روزانه

- **دستی:** روی `start.bat` دو بار کلیک کنید. مرورگر باز می‌شود. پنجره‌ی سیاه تا پایان کار باز بماند.
- **خودکار:** یک بار `install_autostart.bat` را اجرا کنید. از این به بعد با ورود به ویندوز، برنامه بی‌صدا و بدون پنجره بالا می‌آید.
- فایل **`Findent.url`** را روی دسکتاپ کپی کنید تا منشی فقط روی آن کلیک کند (آدرس: `http://localhost:8000`).
- اگر مشکلی پیش آمد، فایل‌های `data/server.log` و `data/findent.log` را ببینید.

## حساب‌ها و دسترسی‌ها

مدیر با آدرس `http://localhost:8000/admin/` وارد بخش «کاربران» می‌شود، کاربر جدید می‌سازد و در قسمت «گروه‌ها» یکی از دو گروه را به او می‌دهد. هر نفر حساب جدا دارد.

| کار | منشی | دکتر | مدیر |
|---|:---:|:---:|:---:|
| جستجو و دیدن پرونده | ✓ | ✓ | ✓ |
| ثبت و ویرایش بیمار | ✓ | ✓ | ✓ |
| ثبت و ویرایش مراجعه | ✓ | ✓ | ✓ |
| حذف مراجعه | | ✓ | ✓ |
| دیدن لاگ تغییرات | | ✓ | ✓ |
| ساخت کاربر و حذف بیمار | | | ✓ |

هر ورود، ثبت، ویرایش و حذف در «لاگ تغییرات» (تنظیمات ← لاگ تغییرات) با نام کاربر و زمان ثبت می‌شود.

## داده‌ها و بکاپ

همه‌ی اطلاعات در پوشه‌ی **`data/`** است (فایل `db.sqlite3`). بکاپ خودکار روزانه و ارسال به Google Drive مرحله‌ی بعدی پروژه است. تا آن زمان، وقتی برنامه بسته است، کل پوشه‌ی `data` را جای دیگری کپی کنید.

## استفاده روی شبکه‌ی داخلی مطب (اختیاری)

قبل از اجرا این دو متغیر را تنظیم کنید (آدرس IP کامپیوتر مطب را جایگزین کنید):

```
set FINDENT_HOST=0.0.0.0
set FINDENT_ALLOWED_HOSTS=192.168.1.10
```

سپس از کامپیوترهای دیگر به `http://192.168.1.10:8000` بروید. ممکن است لازم باشد پورت 8000 در فایروال ویندوز باز شود.

## تنظیمات مهم

- `FINDENT_STRICT_NATIONAL_ID=0`: بررسی الگوریتمی کدملی خاموش می‌شود (برای بیماران اتباع خارجی). فقط ۱۰ رقم بودن بررسی می‌شود.
- شماره‌ی پرونده‌ها ترتیبی هستند (۱، ۲، ۳ ...) و پس از ساخته شدن هرگز تغییر نمی‌کنند.

## اجرای آزمون‌ها

```
venv\Scripts\activate
python manage.py test
```

## ساختار

```

patients/    مدل‌ها، فرم‌ها، ویوها، تاریخ شمسی، آزمون‌ها
templates/   صفحه‌ها
static/      CSS و JS و فونت
data/        دیتابیس و لاگ‌ها (خودکار ساخته می‌شود)

```
